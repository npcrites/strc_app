# Assets Folder

Place your GLB 2.0 model file here:

- **cart-icon.glb** - The 3D model for the one-time order icon

The GLB file will be automatically loaded and displayed with 3D rotation in the TransactionScreen.

## File Requirements

- Format: GLB 2.0 (.glb)
- Recommended size: Keep file size reasonable for mobile performance (< 1MB if possible)
- The model will be automatically scaled to fit the display size
